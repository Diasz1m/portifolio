# Portfólio — Matheus Dias

SPA em React + Vite com bio, experiência, projetos em destaque e demos ao vivo (Bancada, transferência por sockets e conversor de moedas). A lista de repositórios é carregada da API do GitHub.

Site: [diasz1m.github.io/portifolio](https://diasz1m.github.io/portifolio/)

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço que o Vite mostrar (em geral `http://localhost:5173`).
