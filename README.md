# Portfólio — Matheus Dias

SPA em React + Vite com bio, experiência, projetos em destaque e demos ao vivo (Analista B3, Bancada, Flappy Bird, transferência por sockets e conversor de moedas). A lista de repositórios é carregada da API do GitHub.

Os JSON em `public/dados/market/` são a exportação do projeto [market-v1](https://github.com/Diasz1m/market-v1) e alimentam a demo do Analista B3. Para atualizá-los, rode `python exportar_web.py` lá e copie os arquivos gerados.

Site: [diasz1m.github.io/portifolio](https://diasz1m.github.io/portifolio/)

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço que o Vite mostrar (em geral `http://localhost:5173`).
